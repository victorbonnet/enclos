01 / Why enclos

More agents.
Less to keep track of.

As you add agents, it gets harder to remember where they live, what’s running, and what they can access. Enclos brings the agents in its sandboxes into one local workflow, with a central overview and a policy around each sandbox.

01

Your agents, in one place

Run enclos status to see your sandboxes and agents, service state, disk usage, and useful next steps. Add or remove agents and start or stop sandboxes through the same CLI.

02

A home of its own

The agent can install tools and write files in its sandbox home. By default, it cannot write to your other files, and sensitive paths such as SSH keys, browser data, and cloud credentials are blocked from reads.

FILES
03

A say in where it connects

Connections go through a proxy for that sandbox. Unlisted destinations are refused and logged. Review what was blocked, then allow a domain you trust—without restarting the agent.

NETWORK
04

A record you can inspect

Inspect connection metadata, active policy, and recorded sessions. Commands that change Enclos state leave a hash-chained audit record, so you can check what changed.

04 / Take it for a spin

Install once.
Meet your sandbox.

The default installer downloads the latest published binary and verifies its checksum. Rust is needed only for an explicit source build. The first release is pending; the checkout command above lets you try development builds today.

  • An Apple silicon Mac running macOS 14 or later
  • No Rust compiler needed for release installation
  • An account with a model provider Hermes supports
  • About 2.5 GB of free space per Hermes sandbox
Read the full getting started guide ↗

After installation, run these commands one at a time: login and the agent conversation are interactive. Open any login URL in your Mac’s browser. For another provider, allow its API host before signing in; the included model/login endpoints cover the initial OpenAI flow.

AFTER INSTALLATION
# Create Enclos state
enclos init

# A sandbox, then a runtime
enclos sandbox create lab
enclos runtime install hermes --sandbox lab
enclos connect lab -- hermes setup

# Add an agent and check known escape routes
enclos agent add lab/main
enclos policy test lab

# Start services and talk to your agent
enclos sandbox start lab
enclos connect lab -- hermes -p main

# After the conversation, inspect connections
enclos net log lab
enclos status
Run each command separately. Stop if a probe reports OPEN.

05 / A few useful answers

Know what
you’re getting.

Clear boundaries also mean being clear about the limits.

Read the threat model ↗
Is Enclos an AI agent?+

Enclos creates and manages sandboxes for agent runtimes. Hermes is the runtime supported today; it provides the agents, conversations, and tools. You use your own supported model-provider account.

Can I manage all my agents in one place?+

Enclos gives you one CLI to manage and see the agents in the sandboxes it creates on your Mac. Run enclos status for an overview, then use the agent and sandbox commands to add or remove agents, start or stop services, and clean up unused sandboxes. Hermes is supported today; agents installed elsewhere and other machines are outside this overview.

Can it read the rest of my files?+

Host reads are broad by default, with a deny list for sensitive paths such as SSH keys, cloud credentials, browser data, mail, and other agents’ configuration. Other sandboxes and Enclos’s own protected files are also blocked. Writes are limited to the sandbox’s own home by default. This is not a policy that hides every file on your Mac.

How strong is the protection?+

Enclos is designed to reduce accidental damage from buggy or misled agents you mostly trust. It uses macOS Seatbelt and probes known escape routes. It is not a defense against deliberately malicious code exploiting the kernel, and a passing probe does not prove every possible route is closed.

Does an allowed domain make everything behind it safe?+

No. An allowed destination can receive data, and a remote service may fetch other sites on the agent’s behalf. For HTTPS, the proxy records connection metadata, not the encrypted requests or content. The log shows the sandbox’s connections, not everything a remote service does.

Can I have agents with different access?+

Yes—put them in separate sandboxes. Agents in one sandbox share its runtime, policy, proxy, and login. Agents created with Hermes’s own commands inside a sandbox are reported by Enclos; enclos agent add lab/scout explicitly tracks an existing agent without recreating it.

What works today, and what’s still coming?+

Today’s milestone runs Hermes on macOS with sandbox homes, network policies, connection logs, background services, agent discovery, a status overview, escape probes, and the command audit log. Chromium browser tools do not work inside the sandbox yet. Linux, other runtimes, messaging integrations, and managed secrets are future work.

Does it change my existing agents?+

Enclos manages only sandboxes it creates. Each sandbox has its own runtime install and login; it does not adopt your existing host installation. You can inspect sandbox services with enclos sandbox show lab and stop them with enclos sandbox stop lab.
