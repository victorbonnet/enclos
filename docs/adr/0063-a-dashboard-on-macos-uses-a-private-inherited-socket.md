# A dashboard on macOS uses a private inherited socket

This proposes superseding ADR 0028's consequence that Hermes's gateway is a usable browser dashboard, and ADR 0040's macOS exception. The gateway withholds its browser token; opening it produces repeated 401s and reloads. A plain `hermes dashboard` publishes the token on shared loopback. Putting an owner-checked proxy before it leaves that raw TCP port reachable, including through another sandbox's stale service-port allowance.

Decision (proposed; implemented in this PR): use `enclos dashboard <sandbox>` on macOS as well as Linux. On Seatbelt, enclos binds a Unix listener in its host-only run folder and passes that descriptor only to the dashboard session, under the marker's spawn lock. That session is excluded from the normal TCP-listening allowance and cannot bind TCP. Unix sockets inside its own home remain available for IPC. An adapter starts Hermes with its own dependency launcher, supplies the inherited listener to Uvicorn, and maps its authenticated Unix peer to the loopback identity Hermes requires for WebSockets. Changes to the runtime that require a TCP listener fail closed. Adapter source is copied into the runtime from inside the sandbox and removes itself and its bytecode before serving; the launcher also removes the source if startup fails. It is never imported on the host.

The host binds a kernel-chosen port outside enclos's proxy range, so another install's stopped sandbox keeps its reservation. Each TCP client's uid is checked with bounded `lsof` in a connection thread, within the 64-connection limit; another or unknown owner is rejected before forwarding. A random 256-bit URL path capability also protects against a same-uid sandbox retaining access to a former service port. It lives only in the host process and the URL enclos prints, never in the lock, duplicate-run errors or runtime stdout. Each HTTP connection must start with that path; enclos removes it and supplies `X-Forwarded-Prefix`. Ordinary requests ask the runtime to close their connection; only a confirmed WebSocket 101 response becomes a byte relay, and a rejected upgrade closes with an error. Header values remain opaque bytes, legal token names are accepted, and headers beyond the 64 KiB bound get 431 rather than an empty response. The adapter adds `Referrer-Policy: no-referrer` to keep that path out of outgoing navigation headers. Treat the full URL as a credential.

The existing dashboard lock, audited start and end, session policy, secrets, limits, and Ctrl-C cleanup apply. On macOS the runtime files, running sandbox and listening gateway are prerequisites; failure starts no services. Status and startup share these prerequisites; one lazy host-listener snapshot covers all status hints. Linux can offer the command while stopped and keeps ADR 0040's namespace relay and owner check.

CLI JSON moves to schema 2: the unused `dashboard` URL fact and `RuntimeListener::page` are removed; consumers use `dashboard_command`, which may be null when prerequisites are absent. State, audit-file and app-protocol schemas do not change.

Kernel tests on the development Mac show inherited-socket acceptance, Unix IPC binds in the home, and refusal of TCP binds and direct socket-path connections; real Hermes serves HTML, assets, authenticated APIs and WebSockets through the protected path. Owner parsing and missing/incorrect capabilities have regression tests. The second-user test, with a working loopback control, passed on the macOS 15 and 26 CI runners at 8d1945cd; local noninteractive sudo is unavailable. CI reruns it for these changes.
