Command cheatsheet

Every enclos command on one page. lab stands for a sandbox, lab/main for one of its agents. enclos <command> --help gives the full text.

Quick start

From install to talking to a Hermes agent. The commands are the same on macOS and Linux; the getting started guide explains each step.

curl -fsSL https://enclos.dev/install.sh | bash
enclos init
enclos sandbox create lab --template assistant
enclos runtime install hermes --sandbox lab
enclos connect lab -- hermes -p default setup
enclos --yes agent add lab/main
enclos policy test lab
enclos sandbox start lab
enclos connect lab -- main
enclos net log lab

Sandboxes

Each sandbox has its own home, policy and proxy. start, stop and restart take several names at once.

enclos sandbox create lab --template minimal
Create a sandbox. The template is required: minimal reaches only what is listed and its runtime’s hosts, assistant the public web. --backend picks seatbelt or bubblewrap instead of the host’s default
enclos sandbox list
Every sandbox, its policy version and state
enclos sandbox show lab
Its state, policy version, sessions and their processes
enclos sandbox start lab
Run its proxy and its runtime’s services in the background, now and at each login
enclos sandbox stop lab
Stop every service, session and process
enclos sandbox restart lab
Stop, then start again under the active policy
enclos sandbox rm lab
Remove a stopped sandbox, its secrets and its home; --keep-data keeps the home

Runtimes, agents and sessions

The runtime, Hermes today, runs inside the sandbox. enclos installs it, tracks its agents and opens sessions there.

enclos runtime install hermes --sandbox lab
Install a runtime with its own installer, inside the sandbox
enclos runtime configure lab/main --set KEY=VALUE
Change an agent’s settings with the runtime’s own commands; a secret only as ${VAR}. Repeat --set for each setting
enclos runtime configure lab/main --channel telegram --allow-user <id>
Give an agent a bot, its token a secret the policy grants it. --channel app connects the agent to the mobile app
enclos agent add lab/main
Create an agent, or track one the runtime already has; --from <archive> imports the runtime’s own export
enclos agent list lab
Every agent, and the ones made inside the sandbox that enclos does not track
enclos agent rm lab/main
Remove an agent and its files; --keep-data keeps the files
enclos agent export lab/main --to <file>
Export an agent’s runtime data, credentials, presentation and conversation history to a private file
enclos agent import lab/main --from <file>
Import an export; --metadata-only restores only the name and image of an existing agent
enclos connect lab
A shell inside the sandbox
enclos connect lab -- main
Run a command inside it, such as the runtime’s own to talk to an agent
enclos exec lab -- <command>
Run one command for a script; exits with its code
enclos dashboard lab
Open the runtime’s dashboard to you alone, until Ctrl-C

Policy and network

A change applies at once, or waits as the pending policy while sessions run under rules it changes. Every version is kept. How a policy compiles explains which is which.

enclos policy show lab
The active policy and the pending change; --pending shows the pending policy in full, --compiled what the backend runs
enclos policy allow lab api.example.com
Let the sandbox reach a host, host:port or *.domain, without a restart
enclos policy edit lab
Edit policy.toml in your editor, then apply it
enclos policy apply lab
Restart the sandbox into its pending policy
enclos policy discard lab
Drop the pending policy, and any edit not applied
enclos policy history lab
Every version of the policy
enclos policy diff lab
The pending policy against the active one; --from and --to pick versions
enclos policy rollback lab --to <version>
Bring an earlier version back, as a new version
enclos policy refresh lab
Resolve the policy again against this enclos’s templates and defaults; --yes applies what changes
enclos policy test lab
Escape probes from inside the sandbox: every one must fail
enclos net log lab
Every connection, one row per HTTPS tunnel, never its contents; --since 12h
enclos net denied lab
What was refused, to allow what you trust

Secrets

Secrets are kept in the secret store, your Keychain on macOS; the policy decides which agent gets each one. The getting started guide grants a Telegram token step by step.

enclos secret set lab/main-telegram
Store a secret: typed without echo, or piped in
enclos secret list lab
Every secret and how the policy gives it; never a value
enclos secret rm lab/main-telegram
Remove a secret

Mobile app

The bridge serves the enclos app’s paired devices on this host’s loopback; Tailscale puts it on your network.

enclos app serve
Run the bridge in this terminal; --port defaults to 47100
enclos app pair
Show a QR code for the app to scan, then confirm the device that used it
enclos app devices
Every paired device
enclos app unpair <device>
Remove a device: it can no longer connect
enclos app host
The host’s person, whom each agent’s Home conversation belongs to; name a person to make it them
enclos app status
Who can reach the agents, from which devices, and when each was last seen
enclos app log
Connections, disconnections and refusals; -n sets how many lines
enclos app chat lab/main
Talk to an agent through its app channel from this terminal; --conversation goes on with one

Host, logs and audit

enclos init
Create enclos’s folders, state database and audit log, and pick the host’s backend. Safe to run again
enclos status
What is on this host, what it costs on disk, and what you could do; name a sandbox for only that one
enclos doctor
Whether this host runs each backend and each sandbox’s policy compiles
enclos state check
Where enclos’s records and the host differ; changes nothing
enclos state repair
Fix what state check found, and name what is left for you
enclos logs lab -f
The background services’ logs, followed as they write
enclos audit
Every change made through enclos; --since 7d
enclos audit verify
Check that no line of the audit log was edited, deleted or reordered

Flags for every command

--yes
Make changes without asking for confirmation
--dry-run
Show what would change, and change nothing
--json
Print JSON, also in a terminal. It is the default when the output is piped, except for connect, exec and logs
--text
Print readable text, also when the output is piped
