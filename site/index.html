Getting started guide ↗ 
curl -fsSL https://enclos.dev/install.sh | bash
enclos init
enclos sandbox create lab --template assistant
enclos runtime install hermes --sandbox lab

# sign in with your model provider
enclos connect lab -- hermes -p default setup

# talk to your agent
enclos connect lab -- hermes -p default

Worth knowing

  • It limits accidents. enclos is for buggy or misled agents you mostly trust. It is not a defense against malicious code exploiting the kernel.
  • Reads are broad. An agent writes only to its own home, but reads your files, except sensitive paths such as SSH keys.
  • The web is open by default. An agent can send what it reads to a public website. Allowlist mode keeps it to the sites you choose and those its runtime needs.
  • Logs show where, not what. The proxy records where an HTTPS connection goes, not its content.
  • Agents share their sandbox. Use separate sandboxes for agents that need different access.
