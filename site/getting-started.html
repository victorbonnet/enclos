Getting started

From install to talking to an agent. This guide runs Hermes in a sandbox called lab, on a Mac, which is what enclos runs today.

Before you start

  • An Apple silicon Mac on macOS 15 or later.
  • An account with a model provider Hermes supports.
  • About 2.5 GB free per sandbox: each one gets its own Hermes install.

Install enclos

curl -fsSL https://enclos.dev/install.sh | bash

The installer takes the latest release, checks its SHA-256 checksum and version, and puts enclos in ~/.local/bin. If that folder is not on your PATH, run the export line it prints. It never uses sudo, edits your shell files or creates sandboxes.

Create a sandbox and install Hermes

enclos init
enclos sandbox create lab --template assistant

# takes a few minutes
enclos runtime install hermes --sandbox lab

# Hermes's own setup: your provider, its login, a model
enclos connect lab -- hermes -p default setup

The install runs inside the sandbox, through its proxy, so it can write only to the sandbox’s home. The sandbox cannot open a browser: when the login shows a URL, open it in your browser yourself. Every agent in the sandbox shares this login.

The assistant template reaches the public web on ports 80 and 443, and logs every connection. To start with only the hosts Hermes needs, use --template minimal.

Add agents

Hermes comes with a built-in agent, default. Add more with one command:

enclos agent add lab/main
enclos agent add lab/scout
enclos agent list lab

Agents in a sandbox share its runtime, policy, proxy and login, and can read each other’s files. Use separate sandboxes for agents that need different access.

Check the sandbox

enclos policy test lab

This tries known ways out from inside the sandbox, such as reading ~/.ssh, writing outside its home or going around the proxy. Every probe must fail. The last line says READY when none got out, or NOT READY and why.

Talk to an agent

# the proxy and the Hermes gateway, now and at each login
enclos sandbox start lab

# talk to the agent main
enclos connect lab -- main

# a shell in the sandbox, for anything else
enclos connect lab

Whatever a runtime’s documentation tells you to run, put enclos connect lab -- in front of it.

See what it reached

Ask your agent something that needs the web, then look at the log:

enclos net log lab
enclos net denied lab

If something you trust was refused, allow it. It applies at once, and the agent cannot do this itself:

enclos policy allow lab api.example.com:8443

Change what a sandbox may do

# opens policy.toml in your editor
enclos policy edit lab

# what is in force, and every version so far
enclos policy show lab
enclos policy history lab

Set mode = "allowlist" under [network] to keep a sandbox to the hosts you list. A change to the network applies at once. A change to what the sandbox may write waits for you while sessions run; enclos policy apply lab restarts the sandbox into it. How a policy compiles explains why, and lists every setting.

Run more than one

To add a sandbox, repeat the steps with another name. Each one has its own Hermes install, login, policy and proxy, and cannot read the others’ files.

enclos sandbox list
enclos status

Keep an eye on it

# state, policy version, sessions and their processes
enclos sandbox show lab

# the background services' logs
enclos logs lab -f

# every command that changed something, and a check of the log
enclos audit
enclos audit verify

Give an agent a Telegram bot

Secrets live in your Keychain, never in the sandbox’s files. Store the token from @BotFather, grant it to one agent, then connect the channel:

enclos secret set lab/main-telegram

# under [secrets.agents.main] add:
# env = { TELEGRAM_BOT_TOKEN = "secret:lab/main-telegram" }
enclos policy edit lab

enclos runtime configure lab/main --channel telegram --allow-user <your Telegram id>
enclos sandbox start lab

Stop and remove

# every service, session and process of the sandbox
enclos sandbox stop lab

# the sandbox and its home, with Hermes and its login
enclos sandbox rm lab

What does not work yet

Chromium does not start inside a sandbox yet, so Hermes’s browser tools are unavailable. The release notes list every known gap, and the full guide covers the rest, such as bringing an agent from your Mac.
