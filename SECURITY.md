# Security policy

enclos runs AI agents inside sandboxes, so a bug that lets an agent escape its sandbox, bypass a policy or tamper with the audit log is a security vulnerability.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability**.

Include what you found, how to reproduce it, and the enclos version (`enclos --version`) and platform you used.

## Supported versions

enclos is pre-1.0. Only the latest release and `main` receive security fixes.
